Sortwise를 쓰는 이유

Sortwise일까, 손으로 정리할까?

파일 탐색기는 파일을 한 묶음씩 옮깁니다. Sortwise는 폴더 전체를 처리하고, 먼저 계획을 보여 주며, 모든 것을 되돌릴 수 있습니다.

작업 Sortwise 파일 탐색기에서 직접
어수선한 폴더를 사진, 문서, 동영상 등으로 분류 클릭 한 번, 준비된 레시피로 선택하고 끌기, 한 묶음씩
사진을 촬영 날짜별로 정리 각 사진에 저장된 날짜를 읽음 촬영 날짜는 열일 뿐, 옮기는 건 직접
중복 파일 찾기 이름과 상관없이 내용으로 비교 중복 파일 찾기 없음
사진 속 내용으로 사진 찾기 ‘해변’이나 ‘강아지’ 입력 대부분의 PC에서 이름과 파일 정보만
수백 개 파일 이름 바꾸기 바꾸기, 번호, 접두사, 접미사, 미리 보기 포함 사진 (1) 같은 번호 이름만
모든 변경을 미리 보기 완전한 계획, 원하는 항목 체크 해제 끄는 순간 바로 이동

모든 종류의 어수선함을 앱 하나로

다운로드 폴더

설치 파일, PDF, ZIP, 이미지를 종류별 폴더로 분류하고 오래된 설치 파일은 따로 치웁니다.

어수선한 바탕 화면

바탕 화면을 한 번에 비워도 잃어버리지 않습니다. 각 파일이 어디로 갔는지 기록에 남습니다.

수년간의 사진

휴대폰과 카메라 사진을 각 사진 안의 날짜로 연도와 월별로 정리하고, RAW와 JPG는 늘 함께 둡니다.

중복 파일과 디스크 공간

내용으로 찾은 복사본, 비슷한 사진, 연사와 흐린 사진, 중단된 다운로드. 남는 것은 휴지통으로.

청구서와 서류

스캔한 명세서와 청구서를 내용(날짜, 보낸 사람, 문서 종류)으로 이름 짓고 연도별로 정리합니다.

음악과 동영상

곡은 아티스트와 앨범 태그로 정리하고, 이름이 달라도 중복 동영상을 찾아냅니다.

모든 기능

Sortwise가 하는 모든 일, 자세히

파일과 사진 정리하기

  • 한 번의 클릭으로 쓰는 완성된 레시피: 파일 종류별, 연도와 월별, 연도별, 종류 다음 연도별, 카메라별, 또는 스크린샷 따로 빼두기.
  • 이미 쓰던 정리 방식을 이어 가세요. Sortwise는 몇 해 전에 만들어 둔 폴더 구조를 읽어, 멈춘 바로 그 지점부터 이어 가는 규칙을 씁니다.
  • 원하는 바를 내 말로 설명하세요. “청구서는 연도별로 문서에” — 로컬에서 도는 언어 모델이 규칙 초안을 써 주면 확인만 하면 됩니다.
  • 제대로 된 규칙 편집기: 확장자, 이름, 경로, 크기, 날짜, 이미지 크기, 카메라, 인물, 장소, 라벨, 시각적 유사도.
  • 어떤 규칙 묶음이든 레시피로 저장해 두고 원할 때마다 다시 실행하세요.
  • 감시 폴더는 새로 들어온 파일을 알아채고 검토할 수 있게 준비해 둡니다. 스스로 무언가를 옮기는 일은 결코 없습니다.
  • 함께 있어야 할 파일은 함께 남습니다. RAW와 그 JPG, 동영상과 딸린 파일이 갈라지는 일은 없습니다.
  • 보호된 시스템 위치는 그 자리에서 거부됩니다.

일괄 이름 바꾸기
