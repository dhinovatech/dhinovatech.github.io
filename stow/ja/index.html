整理の仕組みが失敗したのではありません。人生が起きただけです。

四千個ものものが入ったダウンロード フォルダー。三台のスマートフォン、二台のカメラ、十年分のスクリーンショットが同居するピクチャ フォルダー。「休暇 2019」「休暇のコピー」「休暇(最終)」という名前のフォルダーが並び、どれがどれだか見分けようがありません。

手作業でもできますが、誰も最後までやり遂げません。クラウド サービスは代わりにやってくれます — 個人ライブラリ全体を他人のコンピューターにアップロードすることによって。スクリプト可能なツールは言われたとおりに正確に動きますが、それはルール構文を学び、まず複製で試す気がある場合に限られます。そしてどれもが肝心の場面で、これから一万件のファイルを走査する処理があなたの意図したものだと信じてくれ、と求めてきます。

Stowは、散らかった「ダウンロード」フォルダー、肥大化した写真ライブラリ、中身の分からない謎のフォルダーに終止符を打ちます。オンデバイス画像認識、ローカル文書OCR、CPU言語モデルを搭載し、インテリジェントな整理プランを算出し、重複ファイルやピンボケ写真を検出し、隠れた不要データを一掃します。

クラウドサーバーへの通信、テレメトリ送信、バックグラウンド追跡は一切行わず、すべての処理がお使いのPC上でのみ実行されます。承認されたプレビューなしにファイルが移動することはなく、ファイルが永久に削除されることもありません。さらに、あらゆる操作は1クリックで元に戻せます。

アーキテクチャによる保証

5つの不変原則

Stowのすべてのレイヤーに組み込まれた、決して妥協のない5つの基本設計保証。

原則 1

100% オフライン＆完全プライベート

アカウント登録不要、クラウドサーバー通信ゼロ、テレメトリ送信ゼロ、行動追跡ゼロ。すべてのAIモデル（画像認識、OCR、言語モデル）はお使いのPCのCPU上で直接動作します。

原則 2

承認プレビューなしには何一つ動かさない

ユーザーの確認なしにファイルを勝手に移動、名前変更、削除することは一切ありません。すべての操作において、事前に確認・承認できる詳細なプレビュー一覧表が提示されます。

原則 3

ファイルを永久削除することは絶対にない

アプリがファイルを完全に消去することはありません。不要データの整理や重複ファイルの削除操作でも、ファイルはWindowsのごみ箱へ安全に移動されるため、いつでも簡単に復元できます。

原則 4

1クリックで即座に元に戻せる

ディスクへの書き込み前にすべての変更がトランザクションとして記録されます。1時間後でも1週間後でも、気が変わったときは1クリックですべてのファイルを元の場所へ正確に戻せます。

原則 5

クラウド同期フォルダーも安心設計

OneDrive、Dropbox、iCloudなどのクラウドプレースホルダー（オンライン専用ファイル）を自動検知。従量制接続などでギガバイト単位の無用な自動ダウンロードを引き起こすことはありません。

安全な実行フロー

使い方・動作の流れ

透明性の高い3つのシンプルステップ。最初から最後まで完全な主導権をあなたに。

1

スキャン＆整理方法の指定

整理したいフォルダーやドライブをStowで選択します。1クリックのプリセットを選ぶか、日常会話の平易な言葉で希望の整理方法を入力するか、またはStowに既存のフォルダー構造を自動学習させます。

2

プレビュー＆確認

ディスク上のファイルが1バイトも動く前に、整理提案の全一覧表を確認できます。すべてのファイルに行、移動先パス、適用ルールが表示されます。除外したいファイルはチェックを外すか直接編集できます。

3

適用＆いつでも1クリックで元に戻す

確信を持って整理を実行します。Stowはすべての処理をアトミックなトランザクションジャーナルに記録してから実行します。1時間後でも1か月後でも、1クリックで元の状態へ戻せます。

スマートダッシュボード＆健全性ハブ

ライブラリの司令塔。インデックス済みファイル総数、管理ストレージ容量、未整理アイテム、回収可能スペースなど、ライブラリの健全性をひと目で把握できます。アクション可能なアテンションカードが、接続されたカメラのSDカードの取り込み準備、整理待ちのダウンロード、不要ファイルの警告、バックアップの更新リマインダーをプロアクティブに通知します。

  • SDカード、保留中ダウンロード、不要ファイル警告を知らせるアテンションカード
  • 整理、不要データ消去、ドライブ照合をワンクリックで実行できるショートカット

選べる5つの整理アプローチ

好みのワークフローを選択できます。すぐに使える1クリックプリセット（ファイル形式別、年/月別、スクリーンショットの仕分け、カメラ機種別）、オンデバイスのローカル言語モデルに日常の言葉で指示を出す方法、Stowに既存のフォルダー規則を自動推論・継続させる方法、ビジュアルルールビルダーで緻密な条件を組む方法、またはルールに基づく一括リネームが可能です。

  • 即戦力となる1クリックプリセット: 種類、日付、カメラメタデータですぐに分類

  • 既存構造の継続: すでに確立されているフォルダーの命名・分類規則を検知して補完
  • ビジュアルルールビルダー: 詳細な条件指定、移動先トークン、衝突回避ロジックを柔軟に設定
  • 一括リネーム機能: 連番カウンター、日付タグ、パターン文字列置換に対応

自動で片付くフォルダー（スマート監視フォルダー）

  • リソースを食う重い常駐サービスなしでドロップゾーンをスマートに監視
  • 監視フォルダーに新しいファイルが入ると自動で整理プランをステージング

第2の柱

デュアルペイン・ライブラリブラウザー＆高機能プレビューペイン

リアルタイムな再帰的フォルダー容量計算と瞬時のリッチプレビューにより、Windows エクスプローラー最大の欠落を解消する先進の代替ブラウザー。

リアルタイムフォルダー容量表示付きデュアルペイン・ライブラリブラウザー

展開可能なディレクトリーツリーと軽快なファイルグリッドでファイルシステム全体を快適に移動できます。Stowは、フォルダー全体の再帰的サイズと含まれる項目数をグリッド上に直接計算・表示することで、Windows エクスプローラーの最大の弱点を克服し、ストレージを消費している場所を瞬時に可視化します。

  • グリッド上で直接計算されるリアルタイムな再帰的フォルダーサイズ＆アイテム数
  • 展開可能なディレクトリツリーとブレッドクラム（パンくずリスト）によるデュアルペイン操作
  • フォルダー作成、名前変更、その場での切り取り/コピー/貼り付けなど直接のファイル操作に対応
  • Windows エクスプローラーやデスクトップアプリとのスムーズな双方向ドラッグ＆ドロップ

万能インスタントプレビューペイン

重い外部アプリケーションを起動することなく、あらゆるファイル形式をその場で素早く確認できます。EXIFメタデータ付きの写真閲覧、解像度やコーデックを表示する動画プレーヤー、PDFやWord文書に対応したドキュメントリーダー、ID3メタデータを表示する音楽プレーヤー、アーカイブのプレビュー機能を備えています。

  • カメラ機種、絞り値、ISO、EXIF詳細情報を確認できる高解像度写真プレビュー
  • 解像度、フレームレート、ビットレート、コーデックを表示する統合動画プレーヤー
  • PDF、Word文書（.docx）、テキストファイルを瞬時に読めるドキュメントリーダー
  • ID3タグ、アルバムアート、ビットレートを確認できるオーディオプレーヤー
  • アーカイブ透視: 解凍することなくZIPやTARアーカイブの中身を確認
第3の柱

高度なクリーンアップ、不要データスイーパー＆重複排除

ファイルを100%安全に保ちながら、無駄に占有されたギガバイトを解放し、散乱した重複ファイルを根絶します。

専用デブリス（不要データ＆残骸）スイーパー

見えないゴミをワンクリックで一掃し、失われたギガバイトを取り戻します。中断された不完全なダウンロード（.crdownload、.part、.download）、エディタやOSの一時ファイル（.DS_Store、Thumbs.db、tempファイル）、溜まったインストーラーの残骸（.exe、.msi）、肥大化した開発者キャッシュ（node_modules、bin/obj、.gradle）、不要になった解凍後フォルダー、0バイトの空ファイルを検出して安全に整理します。

  • 中断されたダウンロード、一時ファイル、OSサムネイルからギガバイト単位の空き容量を回復
  • 「ダウンロード」フォルダーに溜まった古いソフトウェアのインストーラーを実行ファイルごとクリーンアップ
  • 肥大化した開発者用依存関係キャッシュ（node_modules、gradle、bin/obj）を一括パージ
  • 空のフォルダーや解凍後に放置されたアーカイブの残骸をすっきり清掃
  • すべてのクリーンアップはプレビュー表で事前確認され、安全にごみ箱へ移動

完全一致重複検索（ファイル＆フォルダー単位）

ファイル名や保存場所が異なっていても、同一ファイルおよび同一フォルダーツリー全体をバイト単位で正確に特定します。4つの決定論的ポリシー（最高画質優先、最古優先、最新優先、指定フォルダー優先）が残すべきコピーを推薦。余剰な重複ファイルは安全にごみ箱へ移動されます。

  • コンテンツハッシュにより同一ファイルおよび完全ミラーされたフォルダーツリーをグループ化
  • 名前が異なる重複フォルダー（「2021写真」と「バックアップ写真」など）も漏れなく検出
  • ごみ箱への移動方式により、重複削除した余剰ファイルもいつでも元に戻せる安全設計

動画類似重複検索＆写真シャープネス（鮮明度）選別

完全一致の重複検索にとどまりません。再エンコードされた動画、低解像度版（1080p対720pなど）、トリミングされたクリップ、メッセージアプリで圧縮された動画コピーを検出します。写真に対しては、高速連写バースト撮影を自動グループ化し、輪郭の鮮明度（シャープネス）を解析。最もピントが合った1枚の保持を推奨し、ピンボケやブレた写真をフラグ付けします。

  • 再エンコード、サイズ変更、トリミングされた類似動画を漏らさず検知
  • カメラの連写バースト撮影を自動検知してグループ化
  • エッジおよび鮮明度解析により、ピンボケ、手ブレ、ピント外れの写真を自動フラグ付け
第4の柱

ペーパーレス文書、音楽整理＆スマート写真管理

散らかった紙書類の写真やタグのない音楽・メディアコレクションを、整然と整理された美しいライブラリへと変貌させます。

書類写真から複数ページPDFへ変換＆分類

レシート、利用明細書、確定申告・税務書類、公共料金の請求書などを撮影した写真から、整然としたデジタル書庫を構築します。オンデバイスのローカルOCRが、クラウドAPIに書類を送ることなく安全にテキストを抽出。書類種別（レシート、請求書、税務書類、公共料金、銀行明細、契約書）と発行元組織をスマートに判定し、複数枚にわたる書類を1つのPDFにまとめ、標準化されたファイル名へと自動整形します。

  • クラウドへのプライバシー露出ゼロ。100%ローカルOCRが端末内だけでテキストを抽出
  • 書類の種類や発行元組織をインテリジェントに分類
  • 連続して撮影された複数枚の書類を、検索可能な1本の標準PDFへと自動結合
  • 統一された命名規則（例: 「2024-03-15_BankOfAmerica_Statement.pdf」）で自動命名

音楽＆オーディオライブラリのキュレーション

MP3、FLAC、M4A、WAV、OGG形式にわたるID3タグとオーディオメタデータを読み込んでインデックス化。「トラックアーティスト」と「アルバムアーティスト」を明確に区別するため、オムニバスやコンピレーションアルバムがバラバラに散らばることなく、1つのフォルダーに整然とまとまります。欠落または不一致のメタデータを修正できる一括タグエディターも内蔵しています。

  • MP3、FLAC、M4A、WAV、OGGを網羅する総合的なID3＆オーディオタグインデックス
  • 「アルバムアーティスト」基準のフォルダー分けにより、オムニバスやサントラの分散を防止
  • トラック番号、アーティスト、発売年、ジャケット画像を修正できる内蔵の一括タグエディター

完全オフライン・ベクトル世界地図＆SDカード取り込み

外部のWebマップタイルを読み込んだりGPS位置情報を送信したりすることなく、100%オフラインで描画されるインタラクティブなベクトル世界地図上で写真の撮影場所を探索できます。接続されたSDカードやカメラを自動検出し、RAW + JPEGのコンパニオン関係を保持したまま1クリックで安全に取り込めます。

  • 外部通信なしの100%オフラインキャンバス上に位置情報付き写真をマッピングするベクトル世界地図
  • カメラやSDカードの接続を瞬時に感知し、1クリックで取り込みを実行
  • RAW+JPEGや動画+字幕ファイルのペア関係を厳格に保持して整理・移動
第5の柱

ストレージ回収、差分同期＆高度なWindows統合

エンタープライズ水準の安全性、ドライブ間の差分照合、そしてWindows OSとの強固な親和性。

指定フォルダー照合＆差分同期

「メインライブラリに入っていないデータが、外付けバックアップドライブ側にどれだけあるか？」という日常の疑問を解決します。2つのフォルダーツリーまたはドライブを比較し、ファイルを「コピー先に存在しない」「完全一致」「競合/変更あり」の3つに分類。未確認のファイルを勝手に消去することなく、安全なコピー計画を作成して同期します。

  • 2つのフォルダーツリーやドライブを比較し、差分や不一致を漏れなく特定
  • ファイルを「コピー先に不足」「同一」「競合」に自動分類
  • 破壊的なミラー削除を行わず、安全なコピー計画で両者の差分を解消

非破壊バックアップ＆ビット腐敗（ビットロット）検証

重要ライブラリの外付けドライブやセカンダリディスクへのワンクリック/スケジュールバックアップを設定可能。コピー元での削除操作を無差別に反映してバックアップ先を消去してしまう危険（破壊的ミラーリング）がありません。内蔵のビット腐敗検証機能がソースとバックアップのSHA-256チェックサムを再照合し、ディスクの劣化や破損セクターによるデータの静かな破損をいち早く検知します。

  • 削除をミラーリングしない非破壊バックアップで新しいファイルを安全に複製
  • SHA-256ハッシュを再照合してストレージの物理的劣化やデータ破損を検知するビット腐敗検証
  • 元の場所または復旧用フォルダーへの復元を事前プレビューできる安全なリストア計画

ボリューム全体容量マップ＆ジャンクション移動

ドライブ全体（C:、D:）のディスク使用量を視覚化し、スキャンルート外にある巨大な容量浪費フォルダーを特定します（TreeSizeやWizTreeに相当）。大容量フォルダー（400GBのピクチャフォルダなど）をセカンダリドライブへ退避させても、元の場所にStowがNTFSディレクトリージャンクションを自動作成するため、ショートカットや各種アプリの設定パスが壊れることなくそのまま機能します。システムの一時ファイルや更新キャッシュも回収可能です。

  • ドライブ全体の巨大フォルダーを直感的に特定できるボリューム全体容量マップ
  • 巨大フォルダーを別ドライブへ移動してもアプリアクセスを壊さないNTFSディレクトリージャンクション
  • Windowsの一時フォルダーや更新キャッシュを特定して容量を解放するシステム領域回収

  • システム全体から一瞬で呼び出せるグローバルクイックランチャー（Win+Shift+F）

四つのモデル、いずれもインストーラーには同梱されていません

それぞれ、そのモデルを必要とする機能を最初に使うときに、サイズを提示して同意を得たうえで初めてダウンロードされ、ソースコードに固定された SHA-256 ハッシュと照合されます。ダウンロード URL はいずれも変更不可能な上流のコミットに固定されているので、取得されるバイト列は常にハッシュを取った当のバイト列です。

断っても製品は完全に機能します。プリセット、手動のルール作成、既存の慣習の学習、検索、容量レポート、ラベル、重複検出は、モデルをまったく必要としません。推論は ONNX Runtime を通じて CPU 上で実行されます — NPU や GPU の実行プロバイダーは登録されておらず、Windows に組み込まれた AI モデルも使いません。

Stow でないもの

  • クラウド写真サービスではありません。何かをバックアップすることも、端末間で同期することも、あなた自身のディスク以外の場所にライブラリの複製を置くこともありません。
  • 自動で中身を空にする重複削除ツールではありません。何も破壊されません。最大限行うのは、あなたが求めたときに余分な複製をごみ箱へ入れることだけです。
  • 自動化サービスではありません。監視フォルダーに届いたファイルには気づきますが、あなたが見ていないあいだに整理してしまうことはありません。
  • ブラック ボックスではありません。どの提案にもそれを生んだルールが、どの却下にも説明が添えられ、計画全体は一つのファイルが動く前に表計算ソフトで読めます。

こんな方のために

ダウンロード フォルダーが埋め立て地になり、ピクチャ フォルダーに三台のスマートフォンの十年分が積み上がっている方。2019 年に整理の仕組みを作り、四か月は見事に維持し、この五年分も同じように片づけたいと思っている方。RAW と JPEG を一緒に保たなければならず、四万枚をどこにもアップロードせずに近似重複を見つけ出したい写真家の方。そしてそのすべてを貫いて、片づけのためだけに個人のファイルを企業のサーバーへ送る気にはなれない方のために。
