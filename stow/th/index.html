แดชบอร์ดอัจฉริยะและศูนย์สุขภาพคลังไฟล์

ศูนย์บัญชาการคลังไฟล์ของคุณ ประเมินความสมบูรณ์ของคลังไฟล์ได้ในทันที ทั้งจำนวนไฟล์ที่ทำดัชนี ขนาดพื้นที่ที่จัดการ รายการที่ยังไม่ได้จัดหมวดหมู่ และพื้นที่ที่กู้คืนได้ การ์ดแจ้งเตือนที่พร้อมให้ดำเนินการจะช่วยแจ้งเตือนการ์ด SD กล้องที่เพิ่งเสียบเข้ามา โฟลเดอร์ดาวน์โหลดที่รอการจัดระเบียบ คำเตือนขยะไฟล์ตกค้าง และการแจ้งเตือนการสำรองข้อมูลอย่างกระตือรือร้น

  • ภาพรวมพื้นที่จัดเก็บไฟล์ ไฟล์ที่ยังไม่ได้จัดเก็บ และพื้นที่ที่กู้คืนได้ทันที
  • การ์ดแจ้งเตือนสำหรับการ์ด SD, ไฟล์ดาวน์โหลดที่รอดำเนินการ และคำเตือนขยะ
  • ทางลัดการดำเนินการใน 1 คลิกเพื่อจัดระเบียบ กวาดขยะ หรือประสานไดรฟ์

5 วิธีในการจัดระเบียบไฟล์ตามใจคุณ

เลือกรูปแบบการทำงานที่คุณต้องการ ไม่ว่าจะเป็นพรีเซ็ตสำเร็จรูปใน 1 คลิก (ตามประเภทไฟล์, ปี/เดือน, แยกภาพหน้าจอ, รุ่นกล้องถ่ายรูป), พิมพ์ความต้องการเป็นภาษาธรรมชาติให้โมเดลภาษาภายในเครื่องจัดการ, ให้ Stow เรียนรู้และจัดไฟล์ตามโครงสร้างเดิมอย่างต่อเนื่อง, สร้างเงื่อนไขที่แม่นยำด้วย Visual Rule Builder หรือเปลี่ยนชื่อไฟล์พร้อมกันเป็นชุดตามกฎ

  • พรีเซ็ตสำเร็จรูปใน 1 คลิก: จัดเก็บทันทีตามประเภท วันที่ หรือข้อมูลกล้อง
  • AI ภาษาธรรมชาติ: พิมพ์ข้อความภาษาธรรมดา แล้ว LLM ในเครื่องจะสร้างกฎที่ปลอดภัยให้
  • สานต่อระบบเดิม: ตรวจจับและจัดหมวดหมู่ตามแบบแผนโฟลเดอร์ที่คุณใช้อยู่เดิม
  • Visual Rule Builder: กำหนดเงื่อนไขละเอียด โทเค็นปลายทาง และตรรกะเมื่อชื่อไฟล์ซ้ำกัน
  • ระบบเปลี่ยนชื่อไฟล์เป็นชุด: ใส่ตัวเลขนับลำดับ แท็กวันที่ และแทนที่ข้อความตามรูปแบบ

โฟลเดอร์ที่จัดระเบียบตัวเองได้ (Smart Watched Folders)

กำหนดกฎให้กับโฟลเดอร์ที่มักจะรก เช่น ดาวน์โหลด หรือ เดสก์ท็อป เมื่อมีไฟล์ใหม่เข้ามา Stow จะเตรียมข้อเสนอการจัดระเบียบในเบื้องหลังและสะกิดแจ้งเตือนพรีวิวอย่างนุ่มนวล พร้อมให้กดยืนยันในคลิกเดียวโดยไม่ต้องเปิดเซอร์วิสเบื้องหลังที่กินทรัพยากรเครื่อง

  • เฝ้าตรวจโฟลเดอร์ได้อย่างมีประสิทธิภาพโดยไม่ต้องรันบริการเบื้องหลังที่หนักเครื่อง
  • จัดเตรียมข้อเสนอแนะที่เรียบร้อยโดยอัตโนมัติเมื่อมีไฟล์ใหม่เข้ามาในโฟลเดอร์
  • ต้องได้รับการอนุมัติจากผู้ใช้ในคลิกเดียวเสมอ ไม่มีการแอบย้ายไฟล์ในขณะที่คุณไม่อยู่

โปรแกรมจัดการไฟล์ยุคใหม่ที่จะมาเติมเต็มสิ่งที่ขาดหายไปใน Windows Explorer ด้วยการคำนวณขนาดโฟลเดอร์ย่อยแบบเรียลไทม์และการแสดงตัวอย่างไฟล์ที่รวดเร็วทันใจ

เบราว์เซอร์คลังไฟล์สองหน้าต่างพร้อมแสดงขนาดโฟลเดอร์แบบเรียลไทม์

นำทางระบบไฟล์ทั้งหมดของคุณด้วยโครงสร้างไดเรกทอรีแบบขยายได้และตารางไฟล์ที่ตอบสนองรวดเร็ว Stow แก้ไขข้อจำกัดที่ใหญ่ที่สุดของ Windows Explorer โดยคำนวณและแสดงขนาดโฟลเดอร์ย่อยที่แท้จริงและจำนวนรายการในตารางโดยตรง ช่วยให้เห็นจุดที่กินพื้นที่ในทันที

  • คำนวณขนาดโฟลเดอร์ย่อยและจำนวนรายการแบบเรียลไทม์บนตารางไฟล์โดยตรง
  • การนำทางแบบสองหน้าต่างพร้อมโครงสร้างไดเรกทอรีที่ขยายได้และแถบระบุตำแหน่ง (Breadcrumb)
  • จัดการไฟล์ได้โดยตรง: สร้างโฟลเดอร์ เปลี่ยนชื่อ และตัด/คัดลอก/วางได้ทันที
  • ลากและวางไฟล์แบบสองทางกับ Windows Explorer และแอปเดสก์ท็อปได้อย่างราบรื่น

หน้าต่างพรีวิวสารพัดประโยชน์แบบเปิดดูได้ทันที

ตรวจสอบไฟล์ได้ทุกฟอร์แมตในทันทีโดยไม่ต้องเปิดแอปภายนอกที่หนักเครื่อง มาพร้อมระบบดูภาพความละเอียดสูงพร้อมข้อมูล EXIF, เครื่องเล่นวิดีโอพร้อมแสดงความละเอียดและโคเดก, โปรแกรมอ่านเอกสาร PDF และ Word, เครื่องเล่นเสียงพร้อมข้อมูล ID3 และระบบส่องดูไฟล์ในโฟลเดอร์บีบอัด

  • ดูรูปภาพความละเอียดสูงพร้อมข้อมูลกล้อง, รูรับแสง, ISO และสถิติ EXIF
  • เครื่องเล่นวิดีโอในตัว แสดงความละเอียด เฟรมเรต บิตเรต และโคเดก
  • โปรแกรมอ่านเอกสารที่เปิดดูไฟล์ PDF, Word (.docx) และไฟล์ข้อความได้ทันที
  • เครื่องเล่นเพลงพร้อมข้อมูลแท็ก ID3 ภาพหน้าปกอัลบั้ม และการตรวจสอบบิตเรต
  • ตัวตรวจสอบไฟล์บีบอัด: ส่องดูภายในไฟล์ ZIP และ TAR ได้ทันทีโดยไม่ต้องแตกไฟล์
เสาหลักที่ 3

การทำความสะอาดอัจฉริยะ ตัวกวาดล้างขยะตกค้าง และการกำจัดไฟล์ซ้ำ

ทวงคืนพื้นที่หลายกิกะไบต์ที่สูญเปล่าและกำจัดไฟล์ซ้ำที่เกะกะ โดยรักษาไฟล์ของคุณให้ปลอดภัย 100%

ตัวกวาดล้างเศษซากและไฟล์ขยะโดยเฉพาะ

กู้คืนพื้นที่หลายกิกะไบต์ที่เสียไปจากขยะที่ซ่อนอยู่ด้วยการคลิกเพียงครั้งเดียว สแกนหาไฟล์ดาวน์โหลดที่ยังไม่เสร็จ (.crdownload, .part, .download), ไฟล์ตกค้างของระบบปฏิบัติการและโปรแกรมแก้ไข (.DS_Store, Thumbs.db, ไฟล์ temp), ตัวติดตั้งโปรแกรมเก่าที่สะสมอยู่ (.exe, .msi), แคชขนาดใหญ่ของนักพัฒนา (node_modules, bin/obj, .gradle), โฟลเดอร์ที่แตกไฟล์ทิ้งไว้ และไฟล์ขนาด 0 ไบต์

  • กู้คืนพื้นที่จากไฟล์ดาวน์โหลดที่ไม่สมบูรณ์ ไฟล์ชั่วคราว และภาพขนาดย่อของระบบ
  • ล้างไฟล์ติดตั้งโปรแกรมเก่าที่สะสมอยู่ในโฟลเดอร์ดาวน์โหลด
  • ล้างแคชไลบรารีของนักพัฒนาที่กินพื้นที่มาก (node_modules, gradle, bin/obj)
  • กวาดล้างโฟลเดอร์ว่างเปล่าและเศษโฟลเดอร์ที่ถูกแตกไฟล์ทิ้งไว้
  • ทุกการล้างข้อมูลจะแสดงในตารางพรีวิวให้ตรวจสอบและส่งไปยังถังรีไซเคิลอย่างปลอดภัย

โปรแกรมค้นหาไฟล์และโฟลเดอร์ที่ซ้ำกันอย่างแท้จริง

ระบุไฟล์ที่เหมือนกันทุกประการและโครงสร้างโฟลเดอร์ที่ตรงกันแบบไบต์ต่อไบต์ ไม่ว่าชื่อไฟล์หรือตำแหน่งจะต่างกันเพียงใด มีนโยบายอัจฉริยะ 4 แบบที่ช่วยแนะนำไฟล์ที่ควรเก็บไว้ (คุณภาพดีที่สุด, เก่าที่สุด, ใหม่ที่สุด หรือโฟลเดอร์ที่ต้องการ) ส่วนไฟล์ที่เกินมาจะถูกย้ายไปยังถังรีไซเคิลอย่างปลอดภัย

  • จัดกลุ่มไฟล์ที่เหมือนกันและโครงสร้างโฟลเดอร์คู่เหมือนด้วยแฮชเนื้อหา
  • ตรวจจับโฟลเดอร์ที่ซ้ำกันได้แม้ตั้งชื่อต่างกัน (เช่น 'รูปภาพ 2021' กับ 'รูปสำรอง')
  • ปลอดภัยด้วยการย้ายลงถังรีไซเคิล มั่นใจได้ว่าไฟล์ซ้ำที่คัดออกสามารถกู้คืนได้ตลอดเวลา

โปรแกรมค้นหาวิดีโอที่เกือบซ้ำและคัดแยกรูปภาพตามความคมชัด

ก้าวล้ำไปกว่าการค้นหาไฟล์ซ้ำแบบตรงกันเป๊ะ ตรวจจับวิดีโอที่ถูกแปลงรหัสใหม่ เวอร์ชันความละเอียดต่ำกว่า (เช่น 1080p เทียบกับ 720p) คลิปที่ถูกตัดขอบ และวิดีโอที่ถูกบีบอัดจากแอปส่งข้อความ สำหรับรูปภาพ จะตรวจจับภาพถ่ายช็อตต่อเนื่อง (burst) และวิเคราะห์ความคมชัดเพื่อแนะนำภาพที่คมชัดที่สุดให้เก็บไว้ พร้อมทำเครื่องหมายภาพที่เบลอหรือไม่หลุดโฟกัส

  • ระบบตรวจจับวิดีโอที่เกือบซ้ำ ตรวจพบวิดีโอที่ถูกแปลงรหัสใหม่ ย่อขนาด หรือตัดต่อ
  • จัดกลุ่มรูปภาพช็อตต่อเนื่องจากการกดถ่ายรัวของกล้องได้อย่างชาญฉลาด
  • วิเคราะห์ความคมชัดและขอบภาพเพื่อระบุภาพถ่ายที่เบลอ หลุดโฟกัส หรือกล้องสั่น
เสาหลักที่ 4

จัดการเอกสารไร้กระดาษ จัดหมวดหมู่เสียง และคลังภาพถ่าย

เปลี่ยนกองเอกสารกระดาษที่ยุ่งเหยิงและคอลเลกชันสื่อที่ไม่มีแท็กให้เป็นคลังไฟล์ที่มีโครงสร้างสวยงาม

แปลงภาพถ่ายเอกสารกระดาษเป็น PDF หลายหน้า

เปลี่ยนภาพถ่ายใบเสร็จ รายการเดินบัญชี เอกสารภาษี และบิลค่าสาธารณูปโภคให้เป็นตู้เก็บเอกสารดิจิทัลที่เรียบร้อย OCR บนอุปกรณ์ในเครื่องจะสกัดข้อความโดยไม่ต้องส่งเอกสารไปยังคลาวด์ API ระบบการจำแนกประเภทอัจฉริยะจะตรวจจับประเภทเอกสาร (ใบเสร็จ, ใบแจ้งหนี้, แบบฟอร์มภาษี, บิลค่าน้ำค่าไฟ, รายการเดินบัญชี, สัญญา) และองค์กรผู้ออก รวมภาพถ่ายหลายหน้าเข้าเป็นไฟล์เดียว และกำหนดชื่อไฟล์ให้เป็นมาตรฐาน

  • OCR บนอุปกรณ์ 100% ดึงข้อความในเครื่องโดยไม่มีความเสี่ยงด้านความเป็นส่วนตัวบนคลาวด์
  • การจำแนกประเภทอัจฉริยะระบุชนิดของเอกสารและหน่วยงานผู้ออกเอกสาร
  • รวมภาพถ่ายหลายหน้าของเอกสารชุดเดียวกันให้เป็นไฟล์ PDF มาตรฐานที่ค้นหาข้อความได้
  • ตั้งชื่อไฟล์อัตโนมัติอย่างเป็นมาตรฐาน (เช่น '2024-03-15_BankOfAmerica_Statement.pdf')

การจัดการคลังเพลงและไฟล์เสียงอย่างประณีต

อ่านและจัดทำดัชนีแท็ก ID3 และข้อมูลเสียงในฟอร์แมต MP3, FLAC, M4A, WAV และ OGG แยกความแตกต่างระหว่างศิลปินของเพลงกับศิลปินของอัลบั้ม เพื่อให้อัลบั้มรวมเพลงจากหลายศิลปินถูกจัดอยู่ในโฟลเดอร์เดียวกันอย่างเป็นระเบียบ ไม่กระจัดกระจาย มาพร้อมตัวแก้ไขแท็กเสียงในตัวเพื่อซ่อมแซมข้อมูลที่ขาดหายหรือไม่ตรงกัน

  • การจัดทำดัชนี ID3 และแท็กเสียงที่ครอบคลุมทั้ง MP3, FLAC, M4A, WAV และ OGG
  • การจัดกลุ่มตามศิลปินของอัลบั้ม ป้องกันการกระจัดกระจายของอัลบั้มรวมเพลงและเพลงประกอบ
  • ตัวแก้ไขแท็กเป็นชุดในตัว ช่วยแก้ไขชื่อแทร็ก ศิลปิน ปี และภาพหน้าปกที่หายไป

แผนที่โลกเวกเตอร์แบบออฟไลน์และการนำเข้าจากการ์ด SD

สำรวจจุดที่ถ่ายภาพบนแผนที่โลกเวกเตอร์แบบอินเทอร์แอคทีฟที่เรนเดอร์แบบออฟไลน์ 100% โดยไม่ต้องโหลดแผ่นแผนที่จากเว็บภายนอกหรือเปิดเผยพิกัด GPS ตรวจจับการ์ดหน่วยความจำหรือกล้องที่เชื่อมต่อโดยอัตโนมัติสำหรับการนำเข้าในคลิกเดียว พร้อมรักษากลุ่มไฟล์คู่หู RAW + JPEG ไว้อย่างสมบูรณ์

  • แผนที่โลกเวกเตอร์แบบอินเทอร์แอคทีฟ พล็อตภาพถ่ายที่ระบุตำแหน่งบนผืนผ้าใบออฟไลน์ 100%
  • ตรวจจับกล้องและการ์ด SD อัจฉริยะ พร้อมขั้นตอนการนำเข้าไฟล์ในคลิกเดียว
  • รักษากลุ่มไฟล์คู่หูอย่างเคร่งครัด ล็อกไฟล์ RAW+JPEG และวิดีโอ+คำบรรยายให้ไปคู่กันเสมอ
เสาหลักที่ 5

กู้คืนพื้นที่จัดเก็บ การซิงก์ส่วนต่าง และการผสานรวมกับ Windows

ความปลอดภัยระดับองค์กร การประสานความต่างของไดรฟ์อย่างแม่นยำ และการผสานรวมอย่างแนบเนียนกับ Windows

การประสานโฟลเดอร์ตามทิศทางและการซิงก์ส่วนต่าง

ตอบโจทย์คำถามยอดฮิต: 'มีอะไรอยู่ในฮาร์ดไดรฟ์ภายนอกที่ยังไม่มีในคลังไฟล์หลักบ้าง?' เปรียบเทียบโครงสร้างโฟลเดอร์หรือไดรฟ์สองชุด และจัดประเภทไฟล์เป็น 'ขาดหายไปในปลายทาง', 'เหมือนกันทุกประการ' หรือ 'ขัดแย้ง/ถูกแก้ไข' พร้อมจัดทำแผนการคัดลอกที่สะอาดและปลอดภัยเพื่อเติมเต็มส่วนต่างโดยไม่ลบไฟล์ที่ยังไม่ได้ตรวจสอบ

  • เปรียบเทียบโครงสร้างโฟลเดอร์หรือไดรฟ์สองแห่งเพื่อระบุส่วนต่างและข้อขัดแย้ง
  • จัดหมวดหมู่ไฟล์เป็น ขาดหายไปในปลายทาง, เหมือนกันทุกประการ หรือ ขัดแย้งกัน
  • แผนการคัดลอกที่ปลอดภัยช่วยประสานความต่างโดยไม่ลบไฟล์แบบทำลายข้อมูล

การสำรองข้อมูลแบบไม่ทำลายและตัวตรวจสอบความสมบูรณ์ของบิต (Bit-Rot)

ตั้งค่าการสำรองข้อมูลคลังไฟล์สำคัญไปยังไดรฟ์ภายนอกหรือดิสก์สำรองได้ในคลิกเดียวหรือตามกำหนดเวลา คัดลอกไฟล์ใหม่และไฟล์ที่อัปเดตโดยไม่ลบไฟล์ตามต้นทาง ตัวตรวจสอบการเสื่อมสภาพของบิตในตัวจะตรวจสอบค่าแฮช SHA-256 ซ้ำระหว่างต้นทางและข้อมูลสำรองเพื่อตรวจจับความเสียหายของดิสก์หรือเซกเตอร์ที่กำลังจะเสีย

  • งานสำรองข้อมูลแบบไม่ทำลาย คัดลอกไฟล์ใหม่โดยไม่ทำมิเรอร์การลบไฟล์
  • ตัวตรวจสอบความสมบูรณ์ของบิต ตรวจสอบค่าแฮช SHA-256 ซ้ำเพื่อตรวจหาดิสก์เสียหาย
  • ตัววางแผนการกู้คืนที่ปลอดภัย พรีวิวและกู้คืนไฟล์กลับไปยังโฟลเดอร์เดิมหรือโฟลเดอร์กู้คืน

แผนผังพื้นที่ทั้งไดรฟ์และการย้ายตำแหน่งด้วย Junction

แสดงภาพพื้นที่ดิสก์ทั่วทั้งไดรฟ์ (C:, D:) เพื่อค้นหาโฟลเดอร์ขนาดมหึมาที่กินพื้นที่นอกเหนือจากโฟลเดอร์ที่คุณสแกน (เช่นเดียวกับ TreeSize หรือ WizTree) ย้ายโฟลเดอร์ขนาดยักษ์ (เช่น คลังภาพถ่ายขนาด 400 GB) ไปยังไดรฟ์สำรอง โดย Stow จะสร้าง NTFS Directory Junction ไว้ที่ตำแหน่งเดิมโดยอัตโนมัติ ทำให้ทางลัดและแอปพลิเคชันยังคงทำงานได้ตามปกติโดยไม่เกิดข้อผิดพลาด พร้อมกู้คืนพื้นที่จากแคชและไฟล์ชั่วคราวของระบบ

  • แผนผังภาพแสดงพื้นที่ทั่วทั้งไดรฟ์ ระบุโฟลเดอร์ขนาดยักษ์ทั่วทุกไดรฟ์
  • NTFS Directory Junction ช่วยให้ย้ายโฟลเดอร์ขนาดใหญ่ได้โดยไม่ทำให้ลิงก์ของแอปเสียหาย
  • การกู้คืนพื้นที่ระบบ ระบุโฟลเดอร์ temp และแคชอัปเดตของ Windows ที่สามารถกู้คืนได้

การผสานรวมเชิงลึกกับ Windows และโปรไฟล์แบบพกพา

ออกแบบมาเป็นพิเศษสำหรับ Windows คลิกขวาที่โฟลเดอร์ใดก็ได้ใน Windows Explorer เพื่อเลือก 'จัดระเบียบด้วย Stow' หรือ 'ค้นหาไฟล์ซ้ำ' กดปุ่ม Win+Shift+F ได้จากทุกที่เพื่อเรียกใช้ Global Quick Launcher ปลดบล็อกไฟล์เอกสารที่ดาวน์โหลดมาพร้อมกันเป็นชุดด้วยการลบ Mark of the Web (Zone.Identifier) ซ่อมแซมทางลัดบนเดสก์ท็อปและเมนูเริ่มโดยอัตโนมัติเมื่อไฟล์ถูกย้าย และส่งออกโปรไฟล์ JSON แบบพกพาเพื่อนำไปตั้งค่าบนพีซีเครื่องใหม่ได้ในไม่กี่วินาที

  • ผสานรวมกับเมนูคลิกขวาของ Windows Explorer
  • ปุ่มลัด Global Quick Launcher (Win+Shift+F) เพื่อค้นหาระบบได้ทันที
  • ระบบปลดบล็อก Mark of the Web (Zone.Identifier) สำหรับไฟล์ดาวน์โหลดเป็นชุด
  • ระบบซ่อมแซมทางลัดที่รับรู้การย้ายไฟล์ ช่วยให้ลิงก์บนเดสก์ท็อปและเมนูเริ่มยังใช้งานได้
  • ส่งออกโปรไฟล์ JSON แบบพกพาเพื่อย้ายกฎและวิธีจัดระเบียบไปยังพีซีเครื่องใหม่ในไม่กี่วินาที
ความเป็นส่วนตัวและการควบคุมที่ไม่มีการประนีประนอม

เปรียบเทียบ Stow กับระบบอื่น

เหตุผลที่ผู้ใช้เด스크ท็อปเลือก Stow แทนเครื่องมือสคริปต์และบริการคลาวด์

ฟีเจอร์และการรับประกันความปลอดภัย Stow (Dhinovatech) เครื่องมือแบบเดิม / สคริปต์ บริการคลาวด์
ความเป็นส่วนตัวและการรักษาความลับของข้อมูล ออฟไลน์ 100% • ไร้การส่งข้อมูลวิเคราะห์ ไร้บัญชี ไร้เซิร์ฟเวอร์คลาวด์ ออฟไลน์ แต่ขาดระบบอัตโนมัติอัจฉริยะและ AI ไฟล์และข้อมูลเมทาดาตาถูกอัปโหลดไปยังเซิร์ฟเวอร์ของบริษัทภายนอก
การอัปโหลดขึ้นคลาวด์ อัปโหลด 0 ไบต์ (การประมวลผลทั้งหมดอยู่บนพีซีของคุณเท่านั้น) ไม่มี (ทำงานในเครื่องเท่านั้น) บังคับซิงก์ (ต้องใช้แบนด์วิดท์ขนาดหลายกิกะไบต์)
AI ภายในอุปกรณ์ วิชันบน CPU ในเครื่อง, OCR และโมเดลภาษา Phi-4 ผ่าน ONNX ไม่มี (ใช้เพียง regex คงที่หรือเชลล์สคริปต์พื้นฐาน) โมเดลกล่องดำที่เป็นกรรมสิทธิ์บนเซิร์ฟเวอร์
ตารางพรีวิวบังคับก่อนทำรายการ รับประกันการแสดงตารางพรีวิวก่อนที่ไฟล์จะถูกแตะต้องเสมอ ทำงานแบบไม่เห็นผลล่วงหน้าหรือมีความเสี่ยงจากการรันแบตช์สคริปต์ ซิงก์ในเบื้องหลังอย่างคลุมเครือโดยไม่มีการตรวจทานล่วงหน้า
เลิกทำธุรกรรมในคลิกเดียว ย้อนกลับได้ทันทีผ่านเจอร์นัลแบบอะตอมมิกที่บันทึกไว้ก่อนดำเนินการ ต้องกู้คืนด้วยตนเอง สคริปต์ไม่สามารถย้อนกลับได้ ประวัติเวอร์ชันที่ซับซ้อนหรือเสี่ยงต่อการสูญหายอย่างถาวร
ความปลอดภัยของไฟล์คลาวด์เสมือน ตรวจจับ OneDrive/iCloud/Dropbox ไม่บังคับดาวน์โหลดไฟล์โดยไม่จำเป็น ไม่รับรู้ระบบไฟล์เสมือน มักกระตุ้นให้เกิดการดาวน์โหลดไฟล์มหาศาลโดยไม่ได้ตั้งใจ ถูกผูกขาดอยู่ในระบบคลาวด์ของผู้ให้บริการแต่ละราย
การค้นหาไฟล์ซ้ำและเกือบซ้ำ ไฟล์และโฟลเดอร์ที่เหมือนกันแบบไบต์ต่อไบต์ วิดีโอที่เกือบซ้ำ และความคมชัดของภาพ ตรวจสอบได้แค่ชื่อไฟล์ที่ตรงกันหรือแฮชของไฟล์เดี่ยวขั้นพื้นฐานเท่านั้น ค้นหาได้เฉพาะรูปภาพซ้ำเบื้องต้น ไม่สามารถกำจัดวิดีโอหรือโฟลเดอร์ซ้ำได้
ตัวตรวจสอบการเสื่อมสภาพของบิตและความสมบูรณ์ การตรวจสอบข้อมูลสำรองด้วย SHA-256 ในตัว เพื่อดักจับความเสียหายของดิสก์ ต้องใช้ยูทิลิตีบรรทัดคำสั่งที่ซับซ้อนและทำด้วยตนเอง ที่เก็บข้อมูลบนคลาวด์ที่เป็นกรรมสิทธิ์และไม่เปิดเผยรายละเอียด
ราคาและใบอนุญาต ซื้อครั้งเดียวผ่าน Microsoft Store • เป็นเจ้าของตลอดชีพ ยูทิลิตีฟรีที่ไม่ครบวงจร หรือเครื่องมือแบบเสียเงินที่กระจัดกระจาย ค่าธรรมเนียมการสมัครสมาชิกรายเดือน/รายปีที่แพงและต่อเนื่อง

สี่โมเดล ไม่มีตัวใดมาพร้อมตัวติดตั้ง

แต่ละตัวจะถูกดาวน์โหลดเมื่อคุณใช้ฟีเจอร์ที่ต้องการมันเป็นครั้งแรก และต่อเมื่อได้แสดงขนาดให้คุณเห็นและคุณตกลงแล้วเท่านั้น และแต่ละตัวจะถูกตรวจสอบกับค่าแฮช SHA-256 ที่ตรึงไว้ในซอร์สโค้ด ทุกที่อยู่ดาวน์โหลดถูกตรึงไว้กับคอมมิตต้นทางที่เปลี่ยนแปลงไม่ได้ ไบต์ที่ดึงมาจึงเป็นไบต์ชุดเดียวกับที่ใช้คำนวณค่าแฮชเสมอ

การปฏิเสธยังคงเหลือผลิตภัณฑ์ที่ใช้งานได้เต็มรูปแบบ ค่าตั้งสำเร็จรูป ตัวสร้างกฎด้วยมือ การเรียนรู้ธรรมเนียมที่มีอยู่แล้ว การค้นหา รายงานพื้นที่ ป้ายกำกับ และการตรวจจับไฟล์ซ้ำ ล้วนไม่ต้องใช้โมเดลใด ๆ เลย การอนุมานทำงานบนซีพียูผ่าน ONNX Runtime — ไม่มีการลงทะเบียนผู้ให้บริการ NPU หรือ GPU และแอปพลิเคชันไม่ได้ใช้โมเดล AI ที่ติดมากับ Windows

Stow ไม่ใช่อะไร

  • ไม่ใช่บริการรูปภาพบนคลาวด์ มันไม่สำรองข้อมูลใด ๆ ไม่ซิงก์อะไรระหว่างเครื่อง และไม่วางสำเนาคลังของคุณไว้ที่ไหนนอกจากดิสก์ของคุณเอง
  • ไม่ใช่ตัวลบไฟล์ซ้ำที่ล้างตัวเอง ไม่มีอะไรถูกทำลาย อย่างมากที่สุดคือเอาสำเนาส่วนเกินไปไว้ในถังรีไซเคิลตามที่คุณสั่ง
  • ไม่ใช่บริการอัตโนมัติเบื้องหลัง มันจะสังเกตเห็นไฟล์ที่มาถึงโฟลเดอร์ที่เฝ้าดู แต่จะไม่จัดเก็บให้ในตอนที่คุณไม่ได้มอง
  • ไม่ใช่กล่องดำ ทุกข้อเสนอมาพร้อมกฎที่ทำให้เกิดมัน ทุกการปฏิเสธมาพร้อมคำอธิบาย และแผนทั้งหมดอ่านได้ในโปรแกรมตารางคำนวณก่อนที่ไฟล์แม้แต่ไฟล์เดียวจะขยับ

เหมาะกับใคร

เหมาะกับคนที่โฟลเดอร์ดาวน์โหลดกลายเป็นกองขยะ และโฟลเดอร์รูปภาพบรรจุสิบปีจากโทรศัพท์สามเครื่องที่ต่างกัน เหมาะกับคนที่วางระบบจัดเก็บไว้เมื่อปี 2019 ดูแลมันได้อย่างงดงามอยู่สี่เดือน และอยากให้ห้าปีหลังสุดถูกเก็บเข้าที่ด้วยวิธีเดียวกัน เหมาะกับช่างภาพที่ต้องให้ RAW กับ JPEG อยู่ด้วยกัน และต้องหาไฟล์ที่เกือบซ้ำโดยไม่อัปโหลดภาพสี่หมื่นภาพให้ใครทั้งนั้น และร้อยผ่านคนเหล่านี้ทั้งหมด คือคนที่ไม่ยอมส่งไฟล์ส่วนตัวของตัวเองขึ้นไปบนเซิร์ฟเวอร์ของบริษัทใด เพียงเพื่อจะได้จัดระเบียบมัน

คำตอบที่ชัดเจน

คำถามที่พบบ่อย (FAQ)

คำตอบที่ชัดเจนเกี่ยวกับสถาปัตยกรรมความเป็นส่วนตัวของ Stow, AI ออฟไลน์, ความปลอดภัยของไฟล์ และความเข้ากันได้

Stow ไม่มีระบบบัญชีผู้ใช้ ไม่มีเซิร์ฟเวอร์ภายนอก ไม่มี SDK ส่งข้อมูลวิเคราะห์ และไม่มีการติดตามเบื้องหลัง โมเดลแมชชีนเลิร์นนิงทั้งหมด (SigLIP-2 สำหรับค้นหาภาพตามความหมาย, YuNet & SFace สำหรับจัดกลุ่มใบหน้า, OCR ภายในเครื่องสำหรับเอกสาร และ Phi-4-mini สำหรับสร้างกฎจากภาษาธรรมชาติ) ประมวลผลบน CPU ในเครื่องของคุณผ่าน ONNX Runtime โดยตรง รูปภาพ เอกสาร ชื่อไฟล์ โครงสร้างโฟลเดอร์ และคำค้นหาของคุณจะไม่มีวันหลุดออกจากเครื่องพีซีของคุณอย่างเด็ดขาด

ไม่จำเป็นเลย Stow ได้รับการพัฒนาขึ้นสำหรับ Windows 10 และ 11 (ทั้งสถาปัตยกรรม x64 และ ARM64) โดยเฉพาะ และรันไทม์การประมวลผลภายในเครื่องได้รับการปรับแต่งมาอย่างยอดเยี่ยมสำหรับ CPU ทั่วไปของผู้ใช้ตามบ้าน โดยไม่ต้องพึ่งพา GPU หรือ NPU ยิ่งไปกว่านั้น ฟีเจอร์หลัก เช่น พรีเซ็ต, กฎภาพ, การคำนวณขนาดโฟลเดอร์แบบเรียลไทม์, การค้นหาไฟล์ซ้ำ, การกวาดล้างขยะ, การซิงก์ส่วนต่าง และการพรีวิวไฟล์ ไม่จำเป็นต้องใช้โมเดล AI เลย จึงทำงานได้รวดเร็วในทันทีหลังติดตั้ง

Stow ได้รับการออกแบบให้รับรู้ไฟล์เสมือนของระบบคลาวด์ เมื่อสแกนโฟลเดอร์ที่จัดการโดย OneDrive, Dropbox, Google Drive หรือ iCloud ระบบจะตรวจพบไฟล์ตัวแทนจำลองที่เป็นแบบออนไลน์เท่านั้น และจะปฏิเสธการแอบดาวน์โหลดไฟล์ขนาดมหาศาลโดยอัตโนมัติผ่านการเชื่อมต่อที่จำกัดข้อมูลหรือขณะใช้แบตเตอรี่ ช่วยให้ไฟล์บนคลาวด์ของคุณปลอดภัย โดยไม่กินแบนด์วิดท์หรือเปลืองพื้นที่ดิสก์ในเครื่องโดยไม่คาดคิด

ไม่มีไฟล์ใดถูกลบอย่างถาวรโดย Stow การล้างเศษซากขยะ (เช่น การล้างไฟล์ดาวน์โหลดที่ไม่สมบูรณ์หรือตัวติดตั้งเก่า) และการกำจัดไฟล์ซ้ำ จะย้ายรายการเหล่านั้นไปยังถังรีไซเคิลมาตรฐานของ Windows อย่างปลอดภัย หากคุณพบว่าเผลอลบไฟล์ผิดไป ก็สามารถกู้คืนได้ทันทีจากถังรีไซเคิล หรือสั่งการผ่านปุ่มเลิกทำ (Undo) ในคลิกเดียวของ Stow

ก่อนที่ไฟล์ใดๆ จะถูกย้าย เปลี่ยนชื่อ หรือล้างบนดิสก์ Stow จะบันทึกรายการเจอร์นัลธุรกรรมแบบอะตอมมิกที่ย้อนกลับได้ ซึ่งระบุพาธต้นทางและปลายทางที่แน่นอนของทุกรายการ แถบแจ้งเตือนเลิกทำจะปรากฏขึ้นทันทีหลังการดำเนินการ และศูนย์ประวัติ (History Hub) ของ Stow จะเก็บรักษาบันทึกการดำเนินการในอดีตไว้ ทำให้คุณสามารถย้อนกลับเซสชันการจัดระเบียบได้อย่างแม่นยำ แม้จะผ่านไปหลายชั่วโมง หลายวัน หรือหลายสัปดาห์ก็ตาม

เมื่อคุณพิมพ์ข้อความสั่งการ เช่น 'ย้ายใบแจ้งหนี้ทั้งหมดไปไว้ในโฟลเดอร์ Invoices และแยกรูปถ่ายจากกล้องตามปีและเดือน' โมเดลภาษาในเครื่องของ Stow (Phi-4-mini) จะแปลคำขอของคุณให้เป็นกฎการจัดระเบียบที่ปลอดภัยและสามารถพรีวิวได้ โดยโมเดลจะได้รับเฉพาะโครงสร้างภาพรวมของคลังไฟล์ (เช่น จำนวนนามสกุลไฟล์ ช่วงวันที่ และชื่อโฟลเดอร์ระดับบนสุด) เท่านั้น โดยไม่มีการส่งชื่อไฟล์หรือเนื้อหาไฟล์จริงให้โมเดลเลย จากนั้นโค้ดที่ตรวจสอบได้จะประมวลผลกฎเหล่านั้นออกมาเป็นตารางพรีวิวเพื่อให้คุณตรวจสอบและอนุมัติ

ได้แน่นอน Stow มาพร้อมฟังก์ชันการรักษาไฟล์คู่หูอัจฉริยะ โดยไฟล์ RAW จากกล้อง (เช่น CR2, NEF, ARW, DNG) จะถูกผูกเข้ากับไฟล์พรีวิว JPEG/HEIC และไฟล์เมทาดาตา .xmp โดยอัตโนมัติ ในทำนองเดียวกัน ไฟล์วิดีโอจะถูกผูกไว้กับไฟล์คำบรรยาย .srt หรือ .vtt เมื่อ Stow จัดระเบียบหรือย้ายไฟล์หลัก ไฟล์คู่หูทั้งหมดจะถูกย้ายตามไปด้วยพร้อมกันเสมอ

Stow รองรับ Windows 10 (เวอร์ชัน 2004 / บิลด์ 19041 ขึ้นไป) และ Windows 11 ทั้งบนสถาปัตยกรรม 64-bit Intel/AMD (x64) และ Qualcomm Snapdragon (ARM64) โดยเผยแพร่ผ่าน Microsoft Store ในรูปแบบแอปพลิเคชัน MSIX สมัยใหม่ที่ทำงานในแซนด์บ็อกซ์ รับประกันการติดตั้งที่สะอาดปลอดภัย อัปเดตอัตโนมัติ และไม่มีการทิ้งไฟล์ขยะตกค้างในระบบ
