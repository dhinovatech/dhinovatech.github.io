PubMaker pe scurt

PubMaker este un editor de fișiere pub și un program DTP pentru Windows. Deschide și editează fișierele .pub create în Microsoft Publisher și creează flyere, buletine informative, broșuri, felicitări, invitații, etichete, diplome și cărți de vizită cu peste 200 de șabloane. Toate funcțiile sunt gratuite, iar PubMaker funcționează complet offline.
