步骤记录器替代品

Windows 步骤记录器即将退场，Steptell 接棒。

多年来，步骤记录器（psr.exe，又称“问题步骤记录器”）一直是 IT 部门请用户展示问题的方式：开始录制、重现问题、发送 ZIP。Microsoft 已将其弃用：它不再更新，并将在未来的 Windows 版本中移除。官方建议的替代工具（如截图工具和 Clipchamp）录制的是视频，而不是编号步骤。

Steptell 的用法与步骤记录器相同：一个快捷键开始录制，每次单击生成一个带截图的步骤，并为技术支持生成 ZIP。之后，你还能把结果整理成人人都能照着做的教程。它甚至能打开你以前的步骤记录器文件，旧记录不会丢失。

隐私从设计开始

你的屏幕，你的步骤，你的电脑

录制始终可见，输入内容从不被捕获，除非你导出，否则任何内容都不会离开电脑。

Steptell 从不录制你的击键。如果你选择开启，步骤可以显示你键入的简短文本（例如搜索词），但绝不会显示密码或任何看起来像个人信息的内容。密码字段会自动进行模糊处理；Steptell 还会找出屏幕截图中的电子邮件地址、电话号码和卡号，方便你在共享前对其进行模糊处理。指南在你的电脑上加密存储。Steptell 完全脱机工作，不会向任何地方发送任何内容。

  • 按键会被立即丢弃。只有 Ctrl + S 这样的快捷键才会成为步骤。
  • 在步骤中显示少量输入文字的功能默认关闭，且绝不适用于密码框或浏览器隐私窗口。
  • 每张截图中的密码框都会自动模糊。
  • Windows 内置的文字识别可找出电子邮件地址、电话号码、卡号、IBAN 和 IP 地址，方便你在分享前模糊处理。
  • 密码管理器以及你指定的其他应用永远不会被录制。
  • 教程库在电脑上使用 AES-256 加密，导出文件也可以设置密码。
  • 无账户、无广告、无遥测，也不建立任何自有网络连接。
  • 不存在隐藏或后台录制模式。录制指示器始终显示在屏幕上。
