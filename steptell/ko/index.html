단계 레코더 대체

Windows 단계 레코더가 사라집니다. 이제 Steptell이 이어받습니다.

오랫동안 단계 레코더(psr.exe, Problem Steps Recorder라고도 함)는 IT 부서가 문제를 보여 달라고 요청하는 방법이었습니다. 녹화를 시작하고, 문제를 재현하고, ZIP을 보내면 됐죠. Microsoft는 이 도구를 사용 중단했습니다. 더 이상 업데이트되지 않으며 향후 Windows 릴리스에서 제거됩니다. 대신 권장되는 캡처 도구나 Clipchamp 같은 도구는 동영상을 녹화할 뿐, 번호 매긴 단계를 만들지는 않습니다.

Steptell은 단계 레코더와 같은 방식으로 작동합니다. 바로 가기 키 하나로 시작하고, 클릭할 때마다 스크린샷이 있는 단계가 만들어지며, 헬프데스크용 ZIP도 저장됩니다. 그런 다음 누구나 따라 할 수 있는 매뉴얼로 다듬을 수 있습니다. 예전 단계 레코더 파일도 열 수 있어 기존 기록을 잃지 않습니다.

클릭에서 완성된 매뉴얼까지 세 단계

1

평소처럼 작업하세요. 모든 클릭, 바로 가기 키, 스크롤이 스크린샷과 "메모장에서 저장 클릭" 같은 문장이 있는 번호 매긴 단계가 됩니다.

2

편집하고 보호하기

단계 문장을 고치고, 화살표와 설명선을 추가하고, 자르고 확대하세요. 개인정보 검사가 찾은 이메일, 전화번호, 카드 번호를 모두 보여 주고 클릭 한 번으로 흐리게 처리합니다.

3

내보내기 또는 보내기

Word, PDF, PowerPoint, HTML, 동영상, SCORM으로 저장하거나 헬프데스크용 ZIP 하나로 저장하세요. 같은 매뉴얼을 여러 언어로 한 번에 내보낼 수 있습니다.

교사와 학생

수업용 안내서와 과제를 내 언어로, 무료로, 계정 없이 만들 수 있습니다.

설계부터 개인정보 보호

내 화면, 내 단계, 내 PC

녹화 중에는 항상 표시되고, 입력 내용은 절대 기록되지 않으며, 내보내기 전에는 아무것도 PC를 벗어나지 않습니다.

Steptell은 키 입력을 절대 기록하지 않습니다. 원하는 경우 검색어처럼 입력한 짧은 텍스트를 단계에 표시할 수 있지만, 암호나 개인 정보로 보이는 내용은 절대 표시하지 않습니다. 암호 필드는 자동으로 흐리게 처리되며, 스크린샷에서 전자 메일 주소, 전화번호, 카드 번호를 찾아 주므로 공유하기 전에 흐리게 처리할 수 있습니다. 가이드는 PC에 암호화되어 저장됩니다. Steptell은 완전히 오프라인으로 작동하며 어디에도 데이터를 보내지 않습니다.

  • 키 입력은 즉시 버려집니다. Ctrl + S 같은 바로 가기 키만 단계가 됩니다.
  • 입력한 짧은 텍스트를 단계에 표시하는 기능은 기본적으로 꺼져 있으며, 암호 상자나 브라우저의 개인 창에는 절대 적용되지 않습니다.
  • 암호 상자는 모든 스크린샷에서 자동으로 흐리게 처리됩니다.
  • Windows 기본 텍스트 인식으로 이메일, 전화번호, 카드 번호, IBAN, IP 주소를 찾아 공유 전에 흐리게 처리할 수 있습니다.
  • 암호 관리자와 사용자가 선택한 다른 앱은 절대 캡처되지 않습니다.
  • 매뉴얼 라이브러리는 PC에서 AES-256으로 암호화되며, 내보낸 파일도 암호로 보호할 수 있습니다.
  • 계정, 광고, 원격 분석이 없고 자체 네트워크 연결도 하지 않습니다.
  • 숨겨진 녹화나 백그라운드 녹화 모드는 없습니다. 녹화 표시기가 항상 화면에 있습니다.
