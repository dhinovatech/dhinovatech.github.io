Steptell の概要

Steptell は Windows 用のステップ記録・手順書作成ツールです。ショートカット キーを押して操作するだけで、スクリーンショット付きの手順書ができあがり、Word、PDF、PowerPoint、動画に出力できます。すべての機能が無料で、オフラインで動作し、アカウントは不要です。

ステップ記録ツールの後継

Windows のステップ記録ツールはなくなります。これからは Steptell で。

長年、ステップ記録ツール (psr.exe、Problem Steps Recorder とも呼ばれます) は、IT 部門が問題の再現を頼むときの定番でした。記録を開始し、問題を再現して、ZIP を送るだけです。Microsoft はこのツールを非推奨にしました。今後は更新されず、将来の Windows リリースで削除されます。代わりに案内されている Snipping Tool や Clipchamp は動画を録画するもので、番号付きのステップは作れません。

Steptell はステップ記録ツールと同じ感覚で使えます。ショートカット 1 つで開始し、クリックごとにスクリーンショット付きのステップができ、ヘルプデスク用の ZIP も作れます。そのうえで、誰でも手順どおりに進められる手順書に仕上げられます。古いステップ記録ツールのファイルも開けるので、これまでの記録も無駄になりません。

設計段階からのプライバシー

あなたの画面、あなたの手順、あなたの PC

記録中は常に表示され、入力内容は一切取得せず、エクスポートしない限り何も PC の外に出ません。

Steptell がキー入力を記録することはありません。必要に応じて、検索語句など入力した短いテキストをステップに表示できますが、パスワードや個人情報と思われる内容が表示されることはありません。パスワード フィールドは自動的にぼかされます。スクリーンショット内のメール アドレス、電話番号、カード番号も検出されるので、共有する前にぼかすことができます。ガイドは PC 上で暗号化されます。Steptell は完全にオフラインで動作し、データをどこにも送信しません。

  • キー入力はその場で破棄されます。ステップになるのは Ctrl + S のようなショートカットだけです。
  • 入力した短いテキストをステップに表示する機能は既定でオフで、パスワード欄やブラウザーのプライベート ウィンドウには適用されません。
  • パスワード欄はすべてのスクリーンショットで自動的にぼかされます。
  • Windows 標準の文字認識で、メール アドレス、電話番号、カード番号、IBAN、IP アドレスを検出し、共有前にぼかせます。
  • パスワード マネージャーや指定したアプリは決して記録されません。
  • 手順書ライブラリは PC 上で AES-256 により暗号化され、エクスポートにもパスワードを設定できます。
  • アカウント、広告、テレメトリはなく、独自のネットワーク接続も行いません。
  • 隠れた記録モードやバックグラウンド記録モードはありません。記録中の表示が常に画面にあります。
