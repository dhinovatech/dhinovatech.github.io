Steptell โดยสรุป

Steptell คือตัวบันทึกขั้นตอนและเครื่องมือสร้างคู่มือทีละขั้นตอนสำหรับ Windows กดแป้นลัด ทำงานตามปกติ แล้วรับคู่มือพร้อมภาพหน้าจอ ที่พร้อมใช้กับ Word, PDF, PowerPoint หรือวิดีโอ ทุกฟีเจอร์ใช้ฟรี ทำงานออฟไลน์ และไม่ต้องมีบัญชี

Steptell บันทึกทุกการคลิกเป็นขั้นตอนที่มีหมายเลขพร้อมภาพหน้าจอ เป็นตัวแทนรุ่นใหม่ของตัวบันทึกขั้นตอนใน Windows กดแป้นลัดเพียงครั้งเดียว ทำงานตามปกติ แล้วกดอีกครั้ง Steptell จะเขียนขั้นตอนที่เข้าใจง่ายสำหรับแต่ละการคลิก เช่น คลิก "บันทึก" ใน Notepad ได้ใน 25 ภาษา จากนั้นคุณสามารถแก้ไข ใส่คำอธิบายประกอบ และส่งออกเป็นคู่มือที่ผู้อื่นทำตามได้

ใช้แทนตัวบันทึกขั้นตอน

ตัวบันทึกขั้นตอนของ Windows กำลังจะหายไป Steptell พร้อมรับช่วงต่อ

หลายปีที่ผ่านมา ตัวบันทึกขั้นตอน (psr.exe หรือ Problem Steps Recorder) คือวิธีที่ฝ่าย IT ขอให้ผู้ใช้แสดงปัญหา: เริ่มบันทึก ทำให้ปัญหาเกิดซ้ำ แล้วส่งไฟล์ ZIP แต่ Microsoft ได้เลิกใช้เครื่องมือนี้แล้ว: ไม่มีการอัปเดตอีกต่อไปและจะถูกนำออกใน Windows รุ่นต่อไป เครื่องมือที่แนะนำให้ใช้แทน เช่น เครื่องมือสนิป และ Clipchamp บันทึกเป็นวิดีโอ ไม่ใช่ขั้นตอนที่มีหมายเลข

Steptell ทำงานแบบเดียวกับตัวบันทึกขั้นตอน: กดปุ่มลัดเดียวเพื่อเริ่ม ได้ขั้นตอนพร้อมภาพหน้าจอทุกครั้งที่คลิก และได้ไฟล์ ZIP สำหรับฝ่ายช่วยเหลือ จากนั้นยังเปลี่ยนผลลัพธ์ให้เป็นคู่มือที่ใครก็ทำตามได้ และเปิดไฟล์จากตัวบันทึกขั้นตอนเดิมของคุณได้ด้วย จึงไม่มีอะไรสูญหาย

วิธีใช้งาน

จากการคลิกสู่คู่มือที่เสร็จสมบูรณ์ใน 3 ขั้นตอน

1

กดปุ่มลัด

ทำงานตามปกติ ทุกการคลิก ปุ่มลัด และการเลื่อน จะกลายเป็นขั้นตอนที่มีหมายเลขพร้อมภาพหน้าจอและประโยค เช่น “คลิก บันทึก ใน Notepad”

2

แก้ไขและปกป้อง

เขียนขั้นตอนใหม่ เพิ่มลูกศรและคำบรรยาย ครอบตัดและซูม การตรวจสอบความเป็นส่วนตัวจะแสดงอีเมล หมายเลขโทรศัพท์ และหมายเลขบัตรทุกรายการที่พบ และเบลอทั้งหมดได้ในคลิกเดียว

3

ส่งออกหรือส่งต่อ

บันทึกเป็น Word, PDF, PowerPoint, HTML, วิดีโอ หรือ SCORM หรือเป็นไฟล์ ZIP เดียวสำหรับฝ่ายช่วยเหลือ ส่งออกคู่มือเดียวกันหลายภาษาได้ในครั้งเดียว

เหมาะกับใคร

ตัวบันทึกเดียวสำหรับงานทีละขั้นตอนทุกแบบ

รายงานปัญหาให้ฝ่าย IT

เลือก “รายงานปัญหา” แสดงสิ่งที่ผิดพลาด แล้วบันทึก ZIP ไฟล์เดียวที่มีขั้นตอน ภาพหน้าจอ และรายละเอียดระบบ ใส่หมายเลขตั๋ว และหากต้องการ แนบเหตุการณ์ข้อผิดพลาดของ Windows ในช่วงเวลาเดียวกันได้

คู่มือและ SOP

เปลี่ยนกระบวนการใดก็ได้ให้เป็นขั้นตอนการปฏิบัติงานมาตรฐาน พร้อมหน้าปก สารบัญ หัวข้อ เคล็ดลับและคำเตือน ประวัติการแก้ไข และผู้อนุมัติ

การฝึกอบรมและอีเลิร์นนิง

ส่งออกแพ็กเกจ SCORM สำหรับระบบการเรียนรู้ วิดีโอ MP4 พร้อมเสียงบรรยายที่ซูมไปยังทุกการคลิก หรือเดโม HTML ที่คลิกตามได้

QA และรายงานบั๊ก

ช่องผลลัพธ์ที่คาดหวังและที่เกิดขึ้นจริง ความรุนแรง และสภาพแวดล้อม เวลากำกับทุกขั้นตอน และ Markdown ที่พร้อมใช้กับ GitHub, Azure DevOps หรือ Jira

ที่ปรึกษาและทีมซัพพอร์ต

ส่งคู่มือที่ดูเป็นมืออาชีพในรูปแบบ Word หรือ PDF ด้วยสีและหน้าปกของคุณเอง Pro ใส่โลโก้ของคุณบนภาพแทนป้ายกำกับ

ครูและนักเรียน

สร้างคู่มือการเรียนและการบ้านในภาษาของคุณเอง ฟรี โดยไม่ต้องสร้างบัญชี

ออกแบบโดยคำนึงถึงความเป็นส่วนตัว

คำถามที่พบบ่อย

ได้ Steptell บันทึกแบบเดียวกับตัวบันทึกขั้นตอน: กดปุ่มลัด ทำงาน แล้วทุกการคลิกจะกลายเป็นขั้นตอนที่มีหมายเลขพร้อมภาพหน้าจอ และยังเพิ่มสิ่งที่ตัวบันทึกขั้นตอนไม่เคยมี ได้แก่ การแก้ไข คำอธิบายประกอบ การเบลออัตโนมัติ และการส่งออกเป็น Word, PDF, PowerPoint, วิดีโอ และอื่นๆ

Microsoft ได้เลิกใช้ตัวบันทึกขั้นตอน (psr.exe) แล้ว ไม่มีการอัปเดตอีกต่อไปและจะถูกนำออกใน Windows รุ่นต่อไป Steptell เป็นแอปแยกจาก Microsoft Store จึงยังใช้งานได้ต่อไปไม่ว่าตัวบันทึกขั้นตอนจะเป็นอย่างไร

ได้ เปิดไฟล์ ZIP หรือ MHT จากตัวบันทึกขั้นตอน แล้วไฟล์นั้นจะกลายเป็นคู่มือ Steptell ที่แก้ไขได้ พร้อมภาพหน้าจอ ข้อความขั้นตอน และเวลา คุณยังสร้างคู่มือจากโฟลเดอร์ภาพหน้าจอหรือวิดีโอบันทึกหน้าจอได้ด้วย

จริง การบันทึก การแก้ไข การเบลอ การรายงานปัญหา การส่งออกทุกรูปแบบ และทั้ง 25 ภาษาใช้ฟรีโดยไม่จำกัดเวลา การส่งออกแบบฟรีจะมีป้ายกำกับเล็กๆ “สร้างด้วย Steptell” บนภาพ Steptell Pro ซึ่งซื้อครั้งเดียวจะลบป้ายนี้หรือแทนด้วยโลโก้ของคุณ และบัตรผ่าน 24 ชั่วโมงให้ผลแบบเดียวกันสำหรับงานเดียว

ไม่ การกดแป้นพิมพ์จะถูกทิ้งทันที และมีเพียงปุ่มลัดอย่าง Ctrl + S เท่านั้นที่กลายเป็นขั้นตอน ช่องรหัสผ่านจะถูกเบลออัตโนมัติ ส่วนอีเมล หมายเลขโทรศัพท์ และหมายเลขบัตรที่พบในภาพหน้าจอก็เบลอได้ในคลิกเดียวก่อนแชร์

ไม่ Steptell ทำงานออฟไลน์ได้ทั้งหมด ไม่ต้องมีบัญชี และไม่สร้างการเชื่อมต่อเครือข่ายของตัวเอง คู่มือของคุณถูกเก็บแบบเข้ารหัสบนพีซี และจะออกไปก็ต่อเมื่อคุณส่งออกหรือแชร์เท่านั้น

Word, PDF, PowerPoint, HTML, Markdown, ภาพ PNG หรือ JPEG, GIF แบบเคลื่อนไหว, วิดีโอ MP4, SCORM, XLIFF, JSON, ZIP แบบตัวบันทึกขั้นตอน และรูปแบบเปิด .steptell นอกจากนี้ยังพิมพ์หรือคัดลอกทุกขั้นตอนเป็นข้อความได้

ได้ ข้อความขั้นตอนเขียนได้ใน 25 ภาษาใดก็ได้ โดยไม่ขึ้นกับภาษาของแอป ส่งออกคู่มือเดียวเป็นหลายภาษาได้ในครั้งเดียว และส่งข้อความที่คุณเขียนเองให้นักแปลในรูปแบบ XLIFF

เลือก “รายงานปัญหา” แสดงสิ่งที่ผิดพลาด แล้วหยุด ตรวจทานขั้นตอนในหน้าจอเดียว อธิบายปัญหาด้วยคำพูดของคุณ ใส่หมายเลขตั๋วหากมี แล้วบันทึก ZIP ไฟล์เดียวสำหรับฝ่ายช่วยเหลือ ซึ่งตั้งรหัสผ่านป้องกันได้

Steptell สร้างคู่มือแบบทีละขั้นตอน ไม่ใช่วิดีโอหน้าจอต่อเนื่อง แต่สามารถส่งออกคู่มือใดก็ได้เป็นวิดีโอ MP4 ที่ซูมไปยังทุกการคลิก พร้อมเสียงบรรยายจากเสียงที่ติดตั้งใน Windows ได้หากต้องการ

เครื่องมือสร้างคู่มือหลายตัวอัปโหลดภาพหน้าจอของคุณไปยังคลาวด์ของตนและต้องมีบัญชี Steptell เก็บทุกอย่างไว้บนพีซีของคุณ ทำงานออฟไลน์ เบลอข้อมูลสำคัญก่อนแชร์ และทุกฟีเจอร์ใช้ฟรี

ได้ ติดตั้งจาก Microsoft Store และเทมเพลต ADMX สำหรับนโยบายกลุ่มและ Intune ช่วยให้ฝ่าย IT บังคับเบลออัตโนมัติ กำหนดให้ต้องตรวจสอบความเป็นส่วนตัว บล็อกรูปแบบการส่งออก และตั้งขีดจำกัดภาพหน้าจอได้

คู่มือจะถูกบันทึกโดยอัตโนมัติในคลังที่เข้ารหัสบนพีซี พร้อมสแนปช็อตที่กู้คืนได้ ส่งออกข้อมูลสำรองแบบเข้ารหัสหนึ่งไฟล์เพื่อย้ายคลังไปยังพีซีเครื่องอื่น หรือแชร์คู่มือเป็นไฟล์ .steptell แบบเปิดที่ทุกคนที่มี Steptell เปิดได้

รองรับ ทุกฟีเจอร์ใช้งานด้วยแป้นพิมพ์ได้ ทุกตัวควบคุมมีชื่อสำหรับโปรแกรมอ่านหน้าจอ และการเริ่ม หยุดชั่วคราว และหยุดบันทึกจะมีการประกาศ ธีมสว่างและมืดเป็นไปตาม Windows

Windows 10 22H2 หรือ Windows 11 บนพีซี x64 หรือ ARM64 Steptell ออกแบบมาให้ทำงานได้ลื่นไหลบนพีซีทั่วไปที่มี RAM 8 GB และกราฟิกในตัว และไม่ต้องมีสิทธิ์ผู้ดูแลระบบ
