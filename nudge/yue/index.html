Nudge — 離線日記本與本機 AI 伴侶

"你嘅諗法屬於你，絕對唔上雲。"

Nudge 是一款專為 Windows 原生打造的私密、無幹擾的桌面日記本。它將本地純 Markdown 文件的絕對數位主權與從不連接到互聯網的設備上人工智慧伴侶的安靜智慧結合在一起。沒有定期訂閱，沒有遙測，沒有跟踪，也沒有雲鎖定。

在個人軟體已轉變為監控管道的時代，Nudge 代表了對第一原則的深思熟慮、有原則的回歸。您編寫的每一個想法、句子和草稿都嚴格地儲存在您的個人電腦上，作為標準的、人類可讀的 Markdown (.md) 文件，並附有乾淨的 YAML 前言。沒有專有的 blob，沒有脆弱的資料庫。

First Principles

宣言：為什麼我們建立助推

現代雲端期刊的危機、認知隱私權和 50 年測驗。

現代期刊的危機

在過去的十五年裡，從本地個人計算到集中式 SaaS 的轉變已經將私人日記變成了監視管道：第三方工程師可以訪問的雲數據庫、打包到遠程 AI API 的 JSON 有效負載中的親密懺悔、扣押個人記憶的按月付費牆以及使遷移變得痛苦或不可能的專有二進制 blob。

認知隱私原則

我們相信個人的私人內心對話代表了人類意識的神聖核心。認知隱私是探索半成形想法、表達困難情緒、質疑信念和記錄生活的自由，而不會受到外部觀察的寒蟬效應。隱私的唯一真正保證是物理和架構上的不可能：如果應用程式沒有網路權限，它就無法洩露您的日記。

數位長壽原則：50 年測試

五十年後，您或您的孩子還能閱讀今天的文章嗎？過去的專有文字處理器和封閉資料庫格式現在已成為無法存取的數位殘骸。 UTF-8 Markdown 中的純文字是永恆的。到 2076 年，它仍將在人類發明的任何計算平台上立即可讀。

原子寫入、草稿去抖動和衝突安全

每次擊鍵每 500 毫秒都會去抖到 .draft.md 文件，以實現即時崩潰恢復。在原子檔案系統替換之前，將寫入完全儲存到臨時 sidecar (.tmp)。去抖動的 FileSystemWatcher 會偵測來自 Obsidian 或 VS Code 的外部編輯，並將同步編輯分叉到安全同級檔案 (.conflict.md) 中，而不會遺失資料。

低於 150 毫秒的記憶體 BM25 和一次性緩存

使用內存倒排索引和 BM25 相關性評分以及土耳其語感知和字素敏感折疊，即時填充 10,000 多個條目。 .cache/index.bin 快照在 <1.5 秒內載入冷啟動。刪除 .cache 目錄只會損失時間：每個指標、主題分數和索引都可以從原始 Markdown 檔案 100% 重建。

100% On-Device SLM

一面安靜的智力鏡子，從不打斷，從不提供建議，並且 100% 本地運行。

智慧鏡子，而不是聊天機器人

在《Nudge》中，你是作者； AI是一面鏡子。它永遠不會主動提供建議，永遠不會診斷心理狀況，永遠不會中斷您的打字流程，並嚴格檢測並以您的自然語言和腳本進行回應。

Moment 1 開始打字前

入門（空白頁）

基于一周中的某一天、一天中的时间和最近的条目标签的安静的上下文提示。如果人工智能处于离线状态，Nudge 会使用丰富的本地化反思性问题库。在您開始打字的那一刻就消失了。

Moment 2 寫作中途停頓（≥40字，停頓≥6秒）

內嵌輕推（6 秒啟發式）

只有當您在寫下至少 40 個單字後暫停至少 6 秒時，才會在段落下方浮動一個柔和、半透明的問題。 IME 合成 (CJK) 期間暫停。在您下一次擊鍵時立即消失。每節最多 2 次。

Moment 3 結束條目時

深化（進入後）

兩到三個深思熟慮的後續問題，檢查情感潛台詞或未探索的假設。點擊可將乾淨的 Markdown 子標題（### Follow-up）直接附加到文字中，並將遊標置於其下方。

線下週日每週回顧

每個週日，設備上的人工智慧都會合成一份精美的、結構化的一周簡報：中心敘述、反覆出現的線索、情緒變化以及未來一周的兩個前瞻性問題。所有這些都在本地晶片上合成，沒有一個位元組離開您的 PC。

「Ask Your Journal」：引自然語言檢索

問一些概念性問題，例如「我什麼時候第一次考慮轉行？」Nudge 使用 BM25 檢索相關條目，本地 SLM 會透過強制可點擊的引用連結合成連貫的答案。如果我什麼也沒找到，它會說「我在你的日記中找不到任何相關內容」——從數學上講，這是對幻覺的限制。

Compassionate Habits

指標的正念心理學：沒有內疚，沒有羞恥

用人類的同理心而不是有毒的遊戲化來衡量習慣。

具有內建寬限期的條紋

生活發生了。錯過一天不應導致羞恥或重置數月的奉獻。 Nudge 包含自動寬限日：跳過一天可以保持您的動力。我們的程式碼庫包括一個單元測試，確保「錯過的天數」或懲罰指標不會呈現為紅色。

慶祝休息後回歸

Nudge 並沒有懲罰缺勤，而是追蹤回歸率——慶祝生活帶你離開後返回頁面的彈性。

中位數與平均值：誠實寫作量

傳統的平均值會因罕見的長條目而產生偏差。 Nudge 使用統計中位數來代表您真實的典型會話，不存在失真。

五個主要日常工作流程
