Nudge — ไดอารี่และบันทึกประจำวันออฟไลน์พร้อม AI ประจำเครื่อง

"ความคิดของคุณเป็นของคุณ ไม่ใช่ของคลาวด์"

Nudge เป็นบันทึกบนเดสก์ท็อปที่ใกล้ชิดและไร้สิ่งกวนใจ สร้างขึ้นสำหรับ Windows โดยเฉพาะ มันรวมอำนาจอธิปไตยทางดิจิทัลที่สมบูรณ์ของไฟล์ Markdown ธรรมดาในท้องถิ่นเข้ากับความฉลาดอันเงียบสงบของสหาย AI บนอุปกรณ์ที่ไม่เคยเชื่อมต่อกับอินเทอร์เน็ต ไม่มีการสมัครสมาชิกซ้ำ, ไม่มีการตรวจวัดทางไกล, ไม่มีการติดตาม และไม่มีการล็อคอินบนคลาวด์

ในยุคที่ซอฟต์แวร์ส่วนบุคคลถูกเปลี่ยนให้เป็นไปป์ไลน์การเฝ้าระวัง Nudge เป็นตัวแทนของการกลับคืนสู่หลักการแรกอย่างมีหลักการและมีหลักการ ทุกความคิด ประโยค และฉบับร่างที่คุณเขียนจะถูกเขียนลงบนเครื่องส่วนตัวของคุณอย่างเคร่งครัด เป็นไฟล์ Markdown (.md) มาตรฐานที่มนุษย์สามารถอ่านได้ พร้อมด้วยส่วนหน้าของ YAML ที่สะอาดตา ไม่มี blobs ที่เป็นกรรมสิทธิ์ ไม่มีฐานข้อมูลที่เปราะบาง

Architectural Invariants

สามเสาหลักที่มั่นคงของ Nudge

ความคงที่ทางสถาปัตยกรรมของเรา: ความเป็นส่วนตัวแบบออฟไลน์ที่สมบูรณ์ การสะท้อนที่เงียบสงบ และความเห็นอกเห็นใจของมนุษย์

Pillar 1

อิสรภาพแห่งการออฟไลน์ที่แท้จริง

ความเป็นส่วนตัวคือหลักการพื้นฐาน Nudge ไม่มีการเชื่อมต่ออินเทอร์เน็ตใดๆ ขณะทำงาน

AI ประจำเครื่องที่เงียบสงบ

AI เพื่อการสะท้อนตัวตน ทำงานบน CPU, GPU หรือ NPU ของคุณโดยตรง

Pillar 3

สถิติที่อบอุ่นไร้ความกดดัน

ไม่มีตัวเลขสีแดงคอยตำหนิ Nudge มีวันผ่อนปรนและร่วมยินดีเมื่อคุณกลับมาเขียนบันทึกอีกครั้ง

Technical Matrix

ตารางผลิตภัณฑ์และข้อกำหนดทางเทคนิค

การรับประกันทางสถาปัตยกรรมที่เข้มงวดซึ่งออกแบบมาเพื่ออายุการใช้งานที่ยาวนานถึง 50 ปีและประสิทธิภาพต่ำกว่า 150 มิลลิวินาที

มิติ ข้อมูลจำเพาะ การรับประกันสถาปัตยกรรม
ระบบปฏิบัติการ Windows 10 / Windows 11 สร้างขึ้นบน WinUI 3 และ Windows App SDK ที่ทันสมัย รองรับไมกาและอะคริลิกเต็มรูปแบบ
ความบริสุทธิ์รันไทม์ Air-Gapped ออฟไลน์ 100% การโทรผ่านเครือข่ายเป็นศูนย์ในขณะรันไทม์ การวัดและส่งข้อมูลทางไกลในพื้นหลังเป็นศูนย์, บีคอนขัดข้อง หรือการโหลดแบบอักษรระยะไกล
สถาปัตยกรรมการจัดเก็บข้อมูล Markdown ระบบไฟล์ (.md) โปรโตคอลการเขียนอะตอม ส่วนหน้า YAML ที่มนุษย์สามารถอ่านได้ ชั้นฐานข้อมูลที่เป็นกรรมสิทธิ์เป็นศูนย์
เครื่องมือค้นหา หน่วยความจำในเครื่อง BM25 การเรียกค้นข้อความแบบเต็มความยาวต่ำกว่า 150 มิลลิวินาทีจากรายการมากกว่า 10,000 รายการพร้อมคำนำหน้าและการขยายทางสัณฐานวิทยา
รันไทม์สหาย AI SLM บนอุปกรณ์ (DirectML / CPU / NPU) การอนุมานเฉพาะที่ผ่าน ONNX Runtime GenAI & LlamaSharp; โทเค็นเป็นศูนย์ที่ส่งไปยังเซิร์ฟเวอร์ภายนอก
เปิดตัวประสิทธิภาพ < 1.5 วินาทีถึงคาเร็ต การเปิดตัวเย็นโดยตรงสู่พื้นผิวการพิมพ์ที่ใช้งานอยู่ การโหลดดัชนีพื้นหลังและน้ำหนัก AI ที่ขี้เกียจ
ความปลอดภัยและการล็อค Windows Hello ไบโอเมตริกซ์ การจดจำใบหน้า, เซ็นเซอร์ลายนิ้วมือ, PIN; การเข้ารหัสระบบไฟล์ AES-256-GCM เสริมด้วย Argon2id
ประสบการณ์การเขียน การทำงานเชิงลึกที่ไร้สิ่งรบกวน โฟกัสแบบเต็มหน้าจอ F11, การเลื่อนด้วยเครื่องพิมพ์ดีด, โฟกัสย่อหน้าแบบจาง, การพิมพ์แบบกำหนดเอง
การเข้าถึงทั่วโลก การซ้อนทับจับภาพด่วน ปุ่มลัดส่วนกลาง (Win+Alt+N) จะแสดงพื้นผิวการจดบันทึกน้ำหนักเบาภายในเวลาไม่ถึง 200 มิลลิวินาที
เครื่องยนต์หลายภาษา 50+ สถานที่จัดส่งโดยกำเนิด เอ็นจิ้นพหูพจน์ CLDR, การตรวจจับสคริปต์, การรับรู้กราฟ - คลัสเตอร์, ขวาไปซ้าย (RTL) ดั้งเดิม
การทำงานร่วมกันของข้อมูล การนำเข้าและส่งออกสากล นำเข้าวันแรก JSON, การเดินทาง, Diarium, Markdown; ส่งออกหนังสือ PDF, ไฟล์ ZIP, HTML, EPUB

First Principles

แถลงการณ์: ทำไมเราถึงสร้าง Nudge

วิกฤตของวารสารคลาวด์สมัยใหม่ สิทธิ์ในความเป็นส่วนตัวทางกระแสข้อมูล และการทดสอบ 50 ปี

วิกฤตการณ์ของวารสารสมัยใหม่

ในช่วงสิบห้าปีที่ผ่านมา การเปลี่ยนจากคอมพิวเตอร์ส่วนบุคคลในเครื่องไปเป็น SaaS แบบรวมศูนย์ได้เปลี่ยนสมุดบันทึกส่วนตัวให้เป็นไปป์ไลน์การเฝ้าระวัง: ฐานข้อมูลคลาวด์ที่วิศวกรบุคคลที่สามเข้าถึงได้ คำสารภาพใกล้ชิดที่บรรจุอยู่ในเพย์โหลด JSON สำหรับ AI API ระยะไกล เพย์วอลล์รายเดือนที่ถือความทรงจำส่วนตัวเป็นตัวประกัน และ blobs ไบนารีที่เป็นกรรมสิทธิ์ที่ทำให้การย้ายข้อมูลเจ็บปวดหรือเป็นไปไม่ได้

หลักการของความเป็นส่วนตัวแบบ Epistemic

เราเชื่อว่าบทสนทนาภายในส่วนตัวของแต่ละบุคคลแสดงถึงแก่นอันศักดิ์สิทธิ์ของจิตสำนึกของมนุษย์ ความเป็นส่วนตัวแบบญาณคืออิสระในการสำรวจแนวคิดที่ถูกสร้างขึ้นมาเพียงครึ่งเดียว แสดงอารมณ์ที่ยากลำบาก ความเชื่อในการตั้งคำถาม และบันทึกเรื่องราวชีวิตโดยปราศจากผลกระทบอันน่าหวาดหวั่นจากการสังเกตจากภายนอก การรับประกันความเป็นส่วนตัวที่แท้จริงเพียงอย่างเดียวคือความเป็นไปไม่ได้ทางกายภาพและทางสถาปัตยกรรม: หากแอปพลิเคชันไม่มีสิทธิ์เข้าถึงเครือข่าย ไดอารี่ของคุณก็จะไม่รั่วไหล

หลักการอายุยืนแบบดิจิทัล: การทดสอบ 50 ปี
