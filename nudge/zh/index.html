Nudge — 离线日记本与端侧本地 AI 伴侣

"你的思绪归你所有，绝不上云。"

Nudge 是一款专为 Windows 原生打造的沉浸式、无干扰桌面日记软件。它将纯本地 Markdown 文件的绝对数字主权与绝不联网的端侧小语言模型（SLM）智能融为一体。零订阅费、零遥测上传、零后台追踪，彻底告别云端绑架。

当当今个人软件蜕变为数据收割通道时，Nudge 选择坚守本心：你在 Nudge 中写下的每个字、每句话和每个草稿，均以标准 UTF-8 Markdown（.md）格式及 YAML 元数据保存在你的个人硬盘中。没有私有数据库，没有格式锁定。

Architectural Invariants

Nudge 的三大不可动摇基石

我们的建筑不变性：完全的离线隐私、安静的反思和人类的同情心。

Pillar 1

真正的纯离线数据主权

绝对隐私绝非营销口号，而是程序代码的绝对不变式。Nudge 运行时零网络请求，无崩溃回传，无远程字体加载，本地目录完全在你的掌控之下。

Pillar 2

静默克制的端侧 AI 伴侣

人工智能应当服务于人类的反思，而非绑架注意力。Nudge 采用本地量化语言模型直接运行在 CPU、DirectML GPU 或 NPU 上，绝不进行说教或心理诊断，只做忠实的思考镜像。

充满温情、无负罪感的数据统计

传统打卡软件用断签红字制造焦虑，Nudge 则引入连续打卡宽限期、回归鼓励机制、更客观的中位数统计，以及直观的 11 大人生主题环形轮盘。

First Principles

产品宣言：我们为何打造 Nudge

现代云期刊的危机、认知隐私权和 50 年测试。

现代期刊的危机

在过去的十五年里，从本地个人计算到集中式 SaaS 的转变已经将私人日记变成了监视管道：第三方工程师可以访问的云数据库、打包到远程 AI API 的 JSON 有效负载中的亲密忏悔、扣押个人记忆的按月付费墙以及使迁移变得痛苦或不可能的专有二进制 blob。

认知隐私原则

我们相信个人的私人内心对话代表了人类意识的神圣核心。认知隐私是探索半成形想法、表达困难情绪、质疑信念和记录生活的自由，而不会受到外部观察的寒蝉效应。隐私的唯一真正保证是物理和架构上的不可能：如果应用程序没有网络权限，它就无法泄露您的日记。

数字长寿原则：50 年测试

五十年后，您或您的孩子还能阅读今天的文章吗？过去的专有文字处理器和封闭数据库格式现在已成为无法访问的数字残骸。 UTF-8 Markdown 中的纯文本是永恒的。到 2076 年，它仍将在人类发明的任何计算平台上立即可读。

原子写入、草稿去抖动和冲突安全

每次击键每 500 毫秒都会去抖到 .draft.md 文件，以实现即时崩溃恢复。在原子文件系统替换之前，将写入完全保存到临时 sidecar (.tmp)。去抖动的 FileSystemWatcher 检测来自 Obsidian 或 VS Code 的外部编辑，并将同步编辑分叉到安全同级文件 (.conflict.md) 中，而不会丢失数据。

低于 150 毫秒的内存 BM25 和一次性缓存

使用内存倒排索引和 BM25 相关性评分以及土耳其语感知和字素敏感折叠，实时填充 10,000 多个条目。 .cache/index.bin 快照在 <1.5 秒内加载冷启动。删除 .cache 目录只会损失时间：每个指标、主题分数和索引都可以从原始 Markdown 文件 100% 重建。

100% On-Device SLM

深度解析：运行在本地芯片上的 AI 伴侣

绝不打断打字心流、绝不提供居高临下的建议，100% 在本机闭环生成。

智能镜子，而不是聊天机器人

在《Nudge》中，你是作者； AI是一面镜子。它永远不会主动提供建议，永远不会诊断心理状况，永远不会中断您的打字流程，并严格检测并以您的自然语言和脚本进行响应。

Moment 1 开始打字之前

入门（空白页）

基于一周中的某一天、一天中的时间和最近的条目标签的安静的上下文提示。如果人工智能处于离线状态，Nudge 会使用丰富的本地化反思性问题库。在您开始打字的那一刻就消失了。

Moment 2 写作中途停顿（≥40字，停顿≥6秒）

内联轻推（6 秒启发式）

仅当您在写下至少 40 个单词后暂停至少 6 秒时，才会在段落下方浮动一个柔和、半透明的问题。 IME 合成 (CJK) 期间暂停。在您下一次击键时立即消失。每节最多 2 次。

Moment 3 结束条目时

深化（进入后）

两到三个深思熟虑的后续问题，检查情感潜台词或未探索的假设。点击可将干净的 Markdown 子标题（### Follow-up）直接附加到文本中，并将光标置于其下方。

线下周日每周回顾

每个周日，设备上的人工智能都会合成一份精美的、结构化的一周简报：中心叙述、反复出现的线索、情绪变化以及未来一周的两个前瞻性问题。所有这些都在本地芯片上合成，没有一个字节离开您的 PC。

“Ask Your Journal”：被引自然语言检索

问一些概念性问题，例如“我什么时候第一次考虑转行？” Nudge 使用 BM25 检索相关条目，本地 SLM 会通过强制可点击的引用链接合成连贯的答案。如果什么也没找到，它会说“我在你的日记中找不到任何相关内容”——从数学上讲，这是对幻觉的限制。

Compassionate Habits

正念心理学设计：远离内疚与羞耻感

用人类的同理心而不是有毒的游戏化来衡量习惯。

生活发生了。错过一天不应导致羞耻或重置数月的奉献精神。 Nudge 包含自动宽限日：跳过一天可以保持您的动力。我们的代码库包括一个单元测试，确保“错过的天数”或惩罚指标不会呈现为红色。

庆祝休息后回归

Nudge 并没有惩罚缺勤，而是跟踪回归率——庆祝生活带你离开后返回页面的弹性。

中位数与平均值：诚实写作量
