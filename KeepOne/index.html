Why KeepOne

Why another duplicate finder?

Many duplicate finders share the same problems. Some group files that merely have the same name or size, which is not the same as being identical. Some select files automatically and delete them for good with one click. Some hide their best features behind a subscription, fill the screen with ads, or ask you to create an account before you can scan a folder on your own computer.

KeepOne was designed to be the opposite: careful by default, clear at every step, private, and honest about what is free. It is the kind of tool you can hand to a family member without worrying that they will lose the only copy of their wedding photos.

Careful by default

Every match is confirmed byte for byte, every group keeps a copy, and removed files go to the Recycle Bin.

Clear at every step

Plain language, the reason each copy is kept, and exact numbers before anything moves.

Private

No account, no sign-in, no ads and no telemetry. Your files and results stay on your PC.

Honest about what is free

Scan every drive for free. The limit is stated before you scan, and one purchase removes it.

Careful by design

Nothing is ever deleted for good

Safety in KeepOne is not a dialog box asking “Are you sure?” It is built into the engine that does the work, and it applies whatever you click.

Exact duplicates are confirmed byte for byte. Files that only share a name or a size are never grouped.

Every group keeps at least one copy. KeepOne never removes the last one, whatever is selected.

Removed files go to the Recycle Bin, never deleted permanently. If the Recycle Bin can't take a file, it goes to KeepOne's quarantine folder instead.

Right before each file moves, KeepOne checks it and the copy being kept again. If anything changed since the scan, it is left alone.

Undo any of your last 20 cleanups: files go back to exactly where they were.

Windows and program folders are never touched, and cloud files that are not downloaded are never opened.

The tricky details, handled

  • When the Recycle Bin cannot safely take a file (a network or removable drive, a very long path, a very large file), KeepOne moves it to its own quarantine folder instead of letting Windows silently delete it.
  • The quarantine folder keeps each file under its original folder structure, and it is kept even if you uninstall KeepOne, because those files are yours.
  • Hard links count as one file, not as duplicates. Junctions and symbolic links are never followed, and very long paths are fully supported.
  • Every cleanup is recorded before and after it happens, so even after a power cut you always know where every file went.
